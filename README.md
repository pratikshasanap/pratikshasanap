### 📄 [Multi-PDF Advanced RAG Base Chatbot](https://github.com/pratikshasanap/multipdf-rag-base-chatbot)
> **Sub-second, Production-Grade RAG Engine with Pre-Cached Vector Indexing, Hybrid Retrieval, FlashRank Re-ranking, and Groq Llama 3.1 Inference.**

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Vercel-success?style=flat-square&logo=vercel)](https://pratiksha-sanap-multi-pdf-advanced.vercel.app/)
[![GitHub Repo](https://img.shields.io/badge/Repository-multipdf--rag--base--chatbot-181717?style=flat-square&logo=github)](https://github.com/pratikshasanap/multipdf-rag-base-chatbot)

- **Architecture Highlights:**
  - **Hybrid Dual Retrieval:** Combines dense semantic vector search (ChromaDB) with sparse keyword search (BM25) fused via Reciprocal Rank Fusion (RRF k=60).
  - **Re-ranking Pipeline:** Utilizes FlashRank cross-encoder to dynamically filter top candidate passages for accurate context grounding.
  - **Sub-Second Latency:** Ultra-fast LLM generation using Groq's `llama-3.1-8b-instant` and pre-cached vector database with zero-latency cold-starts.
  - **Interactive React UI:** Conversational interface with page citation modals, file ingestion previews, and real-time streaming responses.
  - **Production FastAPI Backend:** Modular REST API with structured Pydantic v2 schemas and serverless deployment on Vercel.
- **Tech Stack:** `Python 3.11`, `FastAPI`, `React.js`, `Groq Llama 3.1`, `LangChain`, `ChromaDB`, `BM25`, `FlashRank`, `Tailwind CSS`, `uv`
